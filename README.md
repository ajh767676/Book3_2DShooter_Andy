# 2D Space Shooter

A 2D space shooter created in Unity for the Book 3 Chapters 10–13 assignment.

## Play the Game

[Click here to play the WebGL version](https://ajh767676.github.io/Book3_2DShooter_Andy/WebGL/)

## How to Play

- Use the arrow keys to move the spaceship.
- Press Space to shoot.
- Destroy enemies to increase your score and level.
- Avoid enemy collisions or your game will end.
- Press Esc to pause or resume the game.
- Use the Exit button to end the game early.

## Features

- Intro, preferences, game, and exit scenes
- Player-name setting
- Enemy-speed dropdown
- Enemy spawn-rate slider
- Count-up game timer
- Score and level tracking
- Pause and resume
- Enemy explosion effects
- Online high-score database
- Windows and WebGL builds
